# ReplicaFlow

> See your information move.

ReplicaFlow is the Control Tower for Information Flow.

It combines visualization, monitoring, administration and learning into a single workspace.

## Why?

Traditional monitoring tools answer:

- Is my server healthy?
- Is replication running?
- How much CPU is used?

ReplicaFlow answers a different question:

> Where is my data right now?
