# ReplicaFlow

> See your data move.

ReplicaFlow is a real-time visualization and Control Tower for database replication and data movement.

Instead of monitoring servers, ReplicaFlow visualizes the journey of your data.

## Why?

Traditional monitoring tools answer:

- Is my server healthy?
- Is replication running?
- How much CPU is used?

ReplicaFlow answers a different question:

> Where is my data right now?
